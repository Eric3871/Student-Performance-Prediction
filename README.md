Data Science Final Project: Student Performance Prediction

Predicts student GPA from study time, absences, tutoring, parental support and extracurricular activities using the Kaggle Students Performance Dataset. We compare Linear Regression, Decision Tree and Random Forest regression against a mean-prediction baseline using MAE, RMSE and R², and we discuss privacy, fairness and the dataset's limitations.
